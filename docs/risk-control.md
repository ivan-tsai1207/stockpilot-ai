# Risk Control

## Hard rules

- Never recommend a trade without a stop-loss concept.
- Never ignore position size.
- Never treat breakout as confirmed without volume and follow-through.
- Never assume a low price means low risk.
- Never let the system speak with certainty when data is incomplete.

## Output expectations

Every answer should mention:

- Current condition
- Main risk
- What would invalidate the thesis
- What to watch next
