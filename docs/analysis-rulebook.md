# Analysis Rulebook

## Core principle

Every analysis must follow:

**Evidence -> Inference -> Strategy -> Risk**

## Rules

1. Do not guarantee profit.
2. Do not invent missing data.
3. Do not use stale data for strong conclusions.
4. Separate short-term setup from long-term value.
5. Always include a risk note.
6. Prefer pullback entries over chasing highs when the data supports it.
7. Distinguish confirmation from assumption.
8. Explain why a stock is hot, not just that it is hot.
