# StockPilot AI

專為台股投資人設計的 AI 投資作業系統。

## 這是什麼

StockPilot AI 的目標，是幫助使用者從資訊過載的市場環境中，走向有結構、有依據的投資決策流程。

目前這份規格也已經明確定義：

- 以個股為單位的獨立 LLM session
- 使用結構化記憶，而不是單一超長對話
- 可版本化的使用者投資策略設定
- 多使用者下的分析與資料隔離邊界
